# 🚀 Dola AI 30s Studio Pro (Chrome Extension)

Dola AI (`https://www.dola.com/chat`)-তে **Seedance 2.5** মডেল দিয়ে ৩০ সেকেন্ডের ভিডিও তৈরির পূর্ণাঙ্গ ব্রাউজার এক্সটেনশন।

---

## 🌟 প্রধান ফিচারসমূহ

1. **Direct 30s API Payload Unlock:**
   - Dola-র নেটিভ ড্রপডাউনে **30s ⚡ Unlocked** অপশন যুক্ত করে।
   - ব্যাকএন্ড API রিকোয়েস্টে `duration: 30` ইনজেক্ট করে।
2. **Auto-Extend Chaining (অটো-লুপ):**
   - সার্ভার যদি সরাসরি ৩০ সেকেন্ড অনুমোদন না দেয়, তবে এই ফিচারটি স্বয়ংক্রিয়ভাবে ভিডিও শেষ হওয়া মাত্র **Extend** বাটনে ক্লিক করে ১০ সে. ➔ ২০ সে. ➔ ৩০ সেকেন্ডের পূর্ণ ভিডিও সম্পন্ন করে।
3. **Floating Studio Widget:**
   - Dola AI স্ক্রিনের নিচে একটি প্রিমিয়াম ফ্লোটিং কন্ট্রোল প্যানেল থাকবে, যেখান থেকে অন/অফ এবং প্রোগ্রেস দেখা যাবে।
4. **Auto-Download 30s:**
   - ৩০ সেকেন্ড সম্পন্ন হওয়া মাত্র স্বয়ংক্রিয়ভাবে আপনার কম্পিউটারে ভিডিও ডাউনলোড করে নেবে।
5. **Batch Prompt Runner:**
   - ক্রোম টুলবার পপআপ থেকে একসাথে একাধিক প্রম্পট দিয়ে এক ক্লিকে Dola-তে পাঠানো যায়।

---

## 🛠️ ক্রোম ব্রাউজারে ইনস্টলেশন গাইড (Installation Guide)

1. গুগল ক্রোম (বা Brave/Edge) ব্রাউজার খুলুন।
2. অ্যাড্রেস বারে যান: `chrome://extensions`
3. উপরের ডান কোণায় **"Developer mode"** টগলটি চালু (ON) করুন।
4. বাম পাশের উপরে **"Load unpacked"** বাটনে ক্লিক করুন।
5. আপনার কম্পিউটার থেকে এই ফোল্ডারটি সিলেক্ট করুন:  
   👉 `E:\Antigravity Material\Dola 30`
6. এক্সটেনশনটি সফলভাবে যুক্ত হয়ে যাবে!

---

## 🎬 কীভাবে ব্যবহার করবেন (How to Use on Dola AI)

1. ব্রাউজারে `https://www.dola.com/chat` পেজে যান এবং একটি রিফ্রেশ দিন (`Ctrl + F5`)।
2. স্ক্রিনের ডান পাশে **"⚡ Dola 30s Studio"** এর ফ্লোটিং প্যানেলটি দেখতে পাবেন।
3. নিচে ইনপুট বারে **Duration** অপশনে ক্লিক করুন (যেখানে আগে শুধু 5s ও 10s ছিল)।
4. এখন মেনুতে সবুজ রঙের **"30s ⚡ Unlocked"** অপশন দেখতে পাবেন, সেটিতে ক্লিক করুন।
5. আপনার প্রম্পট লিখে Generate চাপুন।

> 💡 **পরামর্শ:** যদি কোনো কারণে সার্ভার এক ক্লিকে ৩০ সেকেন্ড রিজেক্ট করে, তবে চিন্তা করবেন না—আমাদের **Auto-Extend Chaining** স্বয়ংক্রিয়ভাবে Extend বাটনে ক্লিক করে মোট ৩০ সেকেন্ড সম্পূর্ণ করবে।
